Reading and writing files in Java is a fundamental task, and Java offers a wide range of options to handle file I/O efficiently. Below is a comprehensive list of all the major ways to read and write files in Java, with detailed explanations, code examples, and best practices.

🔹 BASIC TERMINOLOGY

  • FileReader/FileWriter: Character-based I/O classes.

  • FileInputStream/FileOutputStream: Byte-based I/O classes.

  • BufferedReader/BufferedWriter: Wrapper classes that improve performance using buffering.

  • Scanner: For reading text using regular expressions or line-by-line.

  • PrintWriter: Writing formatted text to files.

  • Files (java.nio.file): High-level, modern utility methods from NIO.

  • RandomAccessFile: For non-sequential read/write (like databases).

📘 1. FileReader and FileWriter (Character Streams)

✅ Use Case:

  • Reading and writing text files (character-based data).

🔸 Reading:

java
import java.io.FileReader;
import java.io.IOException;

try (FileReader reader = new FileReader("file.txt")) {
    int ch;
    while ((ch = reader.read()) != -1) {
        System.out.print((char) ch);
    }
}

🔸 Writing:

java
import java.io.FileWriter;
import java.io.IOException;

try (FileWriter writer = new FileWriter("output.txt")) {
    writer.write("Hello, world!");
}

✅ Best Practices:

  • Always close the reader/writer using try-with-resources.

  • Avoid for large files (better use BufferedReader/Writer).

  • Handles characters, not binary data.

📘 2. BufferedReader and BufferedWriter

✅ Use Case:

  • Efficient reading/writing of text files, line-by-line.

🔸 Reading:

java
import java.io.*;

try (BufferedReader br = new BufferedReader(new FileReader("file.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}

🔸 Writing:

java
import java.io.*;

try (BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))) {
    bw.write("Hello");
    bw.newLine();
    bw.write("World");
}

✅ Best Practices:

  • Use for large text files.

  • Always wrap FileReader/FileWriter in buffering classes.

  • Use newLine() instead of \n for cross-platform compatibility.

📘 3. FileInputStream and FileOutputStream (Byte Streams)

✅ Use Case:

  • Reading/writing binary files (e.g., images, PDFs).

🔸 Reading:

java
import java.io.*;

try (FileInputStream fis = new FileInputStream("image.jpg")) {
    int data;
    while ((data = fis.read()) != -1) {
        // process byte
    }
}

🔸 Writing:

java
import java.io.*;

try (FileOutputStream fos = new FileOutputStream("copy.jpg")) {
    fos.write("Some binary data".getBytes());
}

✅ Best Practices:

  • Wrap with BufferedInputStream/BufferedOutputStream for better performance.

  • Always close streams with try-with-resources.

📘 4. BufferedInputStream and BufferedOutputStream

✅ Use Case:

  • Efficient handling of binary files, with buffering.

java
import java.io.*;

try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("largefile.bin"));
     BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("copy.bin"))) {
    
    byte[] buffer = new byte[1024];
    int length;
    while ((length = bis.read(buffer)) != -1) {
        bos.write(buffer, 0, length);
    }
}

✅ Best Practices:

  • Use buffered versions for performance.

  • Choose a buffer size (e.g., 1024 or 4096 bytes) depending on file size.

📘 5. Scanner (For Reading)

✅ Use Case:

  • Convenient for reading text using delimiters or line-by-line.

java
import java.io.*;
import java.util.Scanner;

try (Scanner scanner = new Scanner(new File("data.txt"))) {
    while (scanner.hasNextLine()) {
        System.out.println(scanner.nextLine());
    }
}

✅ Best Practices:

  • Use for small text files.

  • Not ideal for performance-critical applications.

📘 6. PrintWriter (For Writing)

✅ Use Case:

  • Writing formatted text, numbers, etc., to a file.

java
import java.io.PrintWriter;

try (PrintWriter writer = new PrintWriter("output.txt")) {
    writer.println("Hello");
    writer.printf("Pi: %.2f", Math.PI);
}

✅ Best Practices:

  • Use when formatting is needed (similar to System.out).

  • Supports buffering internally.

📘 7. Files (NIO – java.nio.file.Files)

✅ Use Case:

  • Modern, simplified file operations.

  • Useful for reading all lines, writing strings, or copying files.

🔸 Reading Entire File:

java
import java.nio.file.*;
import java.io.IOException;
import java.util.List;

List<String> lines = Files.readAllLines(Paths.get("file.txt"));
for (String line : lines) {
    System.out.println(line);
}

🔸 Writing:

java
import java.nio.file.*;

Files.write(Paths.get("output.txt"), "Hello\nWorld".getBytes(), StandardOpenOption.CREATE);

✅ Best Practices:

  • Prefer for simple file operations.

  • Files.lines(Path) is lazy and memory-efficient.

  • Use StandardOpenOption.APPEND to append.

📘 8. RandomAccessFile

✅ Use Case:

  • Non-sequential read/write.

  • Useful in databases or file-based indexes.

java
import java.io.RandomAccessFile;

try (RandomAccessFile file = new RandomAccessFile("data.dat", "rw")) {
    file.seek(100);  // Move pointer to byte 100
    file.write("Hello".getBytes());  // Overwrite at that location
    file.seek(0);
    byte[] b = new byte[5];
    file.read(b);
}

✅ Best Practices:

  • Use when random access is required.

  • Not memory efficient for huge files.

  • Don't use unless you need random access.

📘 9. Java NIO (Channels & ByteBuffers)

✅ Use Case:

  • High-performance I/O, non-blocking, suitable for large files and servers.

🔸 Example:

java
import java.io.*;
import java.nio.ByteBuffer;
import java.nio.channels.FileChannel;

try (RandomAccessFile file = new RandomAccessFile("largefile.txt", "rw");
     FileChannel channel = file.getChannel()) {
    
    ByteBuffer buffer = ByteBuffer.allocate(1024);
    while (channel.read(buffer) > 0) {
        buffer.flip();
        while (buffer.hasRemaining()) {
            System.out.print((char) buffer.get());
        }
        buffer.clear();
    }
}

✅ Best Practices:

  • Prefer for scalable I/O, especially servers.

  • Requires understanding of buffers and channels.

📘 10. Object Serialization

✅ Use Case:

  • Write/read entire Java objects to/from files.

🔸 Writing:

java
import java.io.*;

try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("data.obj"))) {
    oos.writeObject(new MyClass("data"));
}

🔸 Reading:

java
import java.io.*;

try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("data.obj"))) {
    MyClass obj = (MyClass) ois.readObject();
}

MyClass must implement Serializable.

✅ Best Practices:

  • Use serialVersionUID for versioning.

  • Avoid serializing sensitive data (or mark as transient).

1. Core Concepts: Buffers & Channels

Buffers

Buffers lie at the heart of NIO. They’re containers for primitive data (byte, char, int, etc.) controlling read/write flow via four key properties:

  • Capacity: Total element storage.

  • Position: Next read/write index.

  • Limit: End index for current operation.

  • Mark: Bookmark inside the buffer to reset later.
    These follow: 0 ≤ mark ≤ position ≤ limit ≤ capacityTaogen's Blogkb.novaordis.com.

Essential operations:

  • clear() → prepare for writing (position=0, limit=capacity).

  • flip() → switch to reading (limit=position, position=0).

  • rewind() → reset reading position to 0 (preserving limit).

  • compact() → move unread data to start, prepare for next write.
    Understand and control these to avoid subtle bugs when toggling between read/write!Taogen's Blognetworkprogram-mmc.blogspot.com.

Channel Types

Channels connect to IO sources/sinks (files, sockets) and move bulk data to/from Buffers. They come in:

  • FileChannel: for files; supports position, mapping, and zero-copy transfers.

  • SocketChannel, ServerSocketChannel: for networking (non-blocking).

  • SeekableByteChannel, ReadableByteChannel, etc.Wikipediarayhon.gitbooks.io.
